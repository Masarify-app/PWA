What's New

Version 1.4.1 October 2026
New
  • SMS confirmation overlay now queues multiple incoming messages — navigate between pending transactions with a position indicator instead of handling them one at a time
  • SMS detection now recognizes bank transfers and ATM/cash withdrawals automatically instead of falling back to a generic debit or credit
  • SMS keyword rules support an "Ignore" pattern to permanently suppress unwanted senders, with optional regex matching for keywords and sender aliases
  • Transfers between accounts in different currencies now support a manual exchange rate — the receiving account's balance updates using the converted amount
Improved
  • Transfer and balance adjustment entries now show distinct icons in transaction lists instead of a generic category icon
  • Account names in transaction details and transfer headers now display in your selected language
  • Bank Accounts and Categories pages now switch between list and expanded layouts based on available screen width
Fixed
  • Transfer and balance adjustment transactions now save with a valid category reference, preventing inconsistent transaction records
  • Saving or editing a transaction no longer returns to the previous screen before the save has actually completed
Version 1.3 September 2026
New
  • AI-powered transaction entry — describe a transaction in plain language and Masarify fills in the details automatically
  • SMS transaction detection — automatically detect and import transactions from bank SMS messages
  • Bank sender association — link SMS senders to your bank accounts for accurate auto-detection
  • Bulk SMS review — review and confirm multiple SMS-detected transactions in one go before importing
  • System-wide content sharing — share financial data and reports to other apps directly from Masarify
Improved
  • Dashboard spending analytics now excludes balance-adjustment transactions — totals reflect real spending only
  • Onboarding account and category selection uses dedicated picker dialogs — easier to browse and choose
Fixed
  • SMS bulk review dialog now opens with the correct default transaction state
Version 1.2 August 2026
New
  • Financial reports — generate detailed income and expense reports with PDF export on Android, iOS, and Web
  • Daily reminders — exact-alarm notifications on Android ensure your reminders fire at precisely the right time
  • In-app messages — important announcements and tips delivered directly inside the app
  • Web splash screen — smooth loading experience while the app initialises in the browser
Improved
  • Accounts, categories, and currencies now sort by most recently used — your favorites appear at the top
  • Backup and restore is more reliable with improved error handling and robustness
Version 1.1 August 2026
Improved
  • Fix Balance dialog now includes a searchable account dropdown — pick any account, not just the default
  • Increase / Decrease indicator is now auto-determined from the entered balance — no manual toggle needed
Fixed
  • Fix Balance dialog was not appearing when opened from the Dashboard
  • Fix Balance from the Transactions page now targets the correct account instead of always the first one
  • App crash when Balance Adjustment transactions appeared in the Dashboard timeline
Version 1.0 July 2026 Initial Release
New
  • Track income, expenses, and transfers across multiple accounts
  • Multi-currency support with live exchange rates
  • Category management with custom icons and colors
  • Dashboard with spending overview and account balances
  • Works as an installable PWA — no app store needed
  • Full offline support powered by local-first SQLite storage
  • Dark mode and light mode with automatic system detection
  • Arabic and English language support
  • Backup and restore your data
  • Notification settings and reminders
